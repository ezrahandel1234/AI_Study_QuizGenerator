# AI_Study_QuizGenerator
It is one of the most Fun ways to study for a school test. All you need are your notes or study guide, and it will generate a quiz to help you remember facts. It is super easy to use and it only takes 5min to set up. Just provide your own API key and it will work every time. I discovered that Groq works very well with my selected model. I can not verify if other models and Ai engines will work. So if you want 100% confidence that it will work, then use the model I have with a Groq, Read-Only API key. Before this code will work you need to run this command, pip install groq
You will also need to make sure you have the newest version of python if you haven't already. You can check your version with, python --version Or py --version. 
Honestly, when I first tried this method of studying, it really felt like I was playing a game instead of reviewing boring notes. The sudden death level at the end is my favorite part. What is also really cool about this code is that it doesn't repeat questions, it shuffles the order of the questions and answers every time, and it dynamically adapts to the length and depth of the provided notes to give you high quality questions. Because of this, the amount of generated questions will vary based off your notes. In the screenshots, it generated 63 questions including the bonus level. That is because I had very long notes so it won't always get that many. When you reach the end of the attempt there will be a box with the core facts. You will need to hit regenerate core facts and set the background to dark mode in order for these to show up.

# AI_Study_QuizGenerator
It is one of the most Fun ways to study for a school test. All you need are your notes or study guide, and it will generate a quiz to help you remember facts. It is super easy to use and it only takes 5min to set up. Just provide your own API key and it will work every time. I discovered that Groq works very well with my selected model. I can not verify if other models and Ai engines will work. So if you want 100% confidence that it will work, then use the model I have with a Groq, Read-Only API key. Before this code will work you need to run this command, pip install groq
You will also need to make sure you have the newest version of python if you haven't already. You can check your version with, python --version Or py --version.
